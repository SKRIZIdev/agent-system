# Ограничения на необратимые действия

Правило «пушить только по команде» записано в инструкциях корневого агента. Но инструкции — это
текст, который модель может неверно применить. Поэтому у необратимых действий есть **второй замок** —
классификатор auto mode Claude Code (`~/.claude/settings.json` → `autoMode`). Он оценивает каждое
действие отдельно от модели, которая его предложила.

## Два уровня

| Уровень | Что блокирует | Как снимается |
|---|---|---|
| `soft_deny` | `git push` в любой remote, ветку или тег — включая побочные пуши (`gh repo create --push`, `gh pr create`) | Прямая команда владельца («пушь», «запушь <репо>») или его «да» на предложение агента, где репо названо |
| `soft_deny` | Деплой и публикация за пределы машины: загрузки на хостинг, выкат на сервер, публикация пакетов | Прямая команда владельца («деплой», «выкатывай») или «да» на предложение, где назван сайт или сервер |
| `hard_deny` | Любой сетевой запрос к живому партнёрскому редиректу `/go/` и к целевым партнёрским URL: `curl`, скрипты, headless-браузеры, линк-чекеры, даже `HEAD` и чтение `Location` | **Ничем.** Партнёрские ссылки проверяет только владелец |

## Почему так

- **Пуш и деплой** обратимы плохо: код уходит на прод или в общий репозиторий. Агенту достаточно одной
  неверно понятой фразы — классификатор требует, чтобы команда была названа явно.
- **Партнёрские ссылки** — автоматический трафик по ним портит статистику партнёрки и может стоить
  аккаунта. Здесь нет ситуации, где агенту нужно по ним ходить, поэтому запрет безусловный.
- Локальные тесты с фиктивной целью (`https://partner.example/`) разрешены.

## Формат в settings.json

```json
{
  "autoMode": {
    "soft_deny": [
      "$defaults",
      "Push Without Owner's Command [must name: the push itself — owner's own words asking to push, or his yes to a proposal that named the repo]: Any `git push` to any remote, branch or tag …",
      "Deploy or Publish Without Owner's Command [must name: the deploy itself …]: Deploying or publishing anything beyond this machine …"
    ],
    "hard_deny": [
      "$defaults",
      "Owner's Referral Links: Any network request to a `/go/` referral redirect on a live (non-local) host …"
    ],
    "environment": "описание среды для классификатора: репозитории и их видимость, хосты, домены, где деплой, где секреты"
  }
}
```

`"$defaults"` стоит первым в обоих списках: без него пропадают встроенные правила Claude Code.
Проверка конфигурации — `claude auto-mode config`.
